## Overview

Rustify replaces Skyrim's pristine weapon and armor textures with high-resolution weathered variants featuring rust, scratches, dents, and aging appropriate to a province ravaged by war and harsh climate. Over 1500 retextured items across all material categories — iron, steel, dwarven, and more — with PBR-accurate metal surface properties for ENB users.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Skyrim Rustify** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **1500+ Retextured Items** | All material weapon and armor types retextured with weathering |
| **High Resolution** | 4K base textures with 2K and 1K performance options included |
| **PBR Metal Surfaces** | ENB-compatible normal maps with physically based metal specularity |
| **Lore Consistency** | Weathering intensity matches lore-appropriate age for each item type |
